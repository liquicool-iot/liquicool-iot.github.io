專業的液冷技術團隊

立冷科技由香港理工大學王鑽開教授團隊創立，專注於數據中心液冷解決方案的研發與應用。

我們致力於為客戶提供高效節能的熱管理技術，通過創新的結構熱鎧甲技術，實現數據中心的智能化溫控管理。

我們的解決方案具有高能效比(PUE < 1.06)、高水效比(WUE < 0.5)和低碳排放的特點。
