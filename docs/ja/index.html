LiquiCool Technologyについて

プロフェッショナルな液冷技術チーム

LiquiCool Technologyは香港理工大学王鑽開教授チームにより設立され、データセンター液冷ソリューションの研究開発・応用に特化しています。

当社は顧客に高効率省エネの熱管理技術を提供することに専念し、革新的な構造熱アーマー技術により、データセンターのインテリジェント温度制御管理を実現します。

当社のソリューションは高エネルギー効率比（PUE < 1.06）、高水効率比（WUE < 0.5）、低炭素排出の特徴を持ちます。
